# Mobil Risk Analiz ve İSG İzleme Sistemi

Bu proje, endüstriyel sahalarda iş güvenliğini artırmak amacıyla geliştirilen gerçek zamanlı bir izleme ve analiz platformudur.

## ✨ Temel Özellikler
* **Dashboard:** Gerçek zamanlı risk takibi ve veri görselleştirme.
* **Mobil Entegrasyon:** Sensör verileriyle anomali tespiti.
* **Akıllı Analiz:** Görüntü ve sensör tabanlı risk yönetimi.

## 🛠 Teknoloji Yığını
* **Frontend:** React.js
* **Backend:** Node.js & Express
* **İletişim:** Socket.io & REST API
